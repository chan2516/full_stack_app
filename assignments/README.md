# Three Separate Assignment Submissions

This project is used for three independent submissions. The application is an Express frontend on port 3000 and a Flask backend on port 5000.

| Folder | Assignment | Run location |
|---|---|---|
| `activity-1-kubernetes` | Docker and Kubernetes with Minikube | Local computer |
| `activity-2-terraform-aws` | Terraform: single EC2, separate EC2, and ECS | AWS |
| `activity-3-ec2-jenkins` | Manual EC2 deployment and Jenkins CI/CD | AWS |

Complete and submit one activity at a time. Each folder contains its own guide, screenshot checklist, and packaging script. Do not submit generated credentials, `.env` files, Terraform state, SSH keys, or Jenkins secrets.

Before packaging, update the GitHub URL and student details in each guide, add the required screenshots, and run that activity's `make-submission.ps1` script.
